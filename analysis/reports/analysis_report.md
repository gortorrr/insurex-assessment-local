# Analysis Report

**สถานะ:** รายงานนี้สร้างจากไฟล์ CSV และ definition ข้อมูลในไฟล์ Excel ที่ได้รับ โดยไม่มีการแก้ไขข้อมูลต้นฉบับ

## Scope and grain

ข้อมูล CSV ถูกวิเคราะห์หนึ่งแถวต่อหนึ่งรายการ campaign 

dataset ไม่มี customer ID, policy ID, agent ID, policy date, premium transaction, payment transaction หรือ contract ledger 

ส่วนไฟล์ Excel ใช้เป็น definition ข้อมูล

Report นี้อธิบายผลตอบรับจากแคมเปญ เท่านั้น

## Findings supported by the supplied data

1. เมื่อพิจารณาตามกลุ่มลูกค้า `Lower Mass` มีอัตราตอบรับข้อเสนอสูงที่สุดที่ 1.2620% หรือ 1,329 รายการจาก 105,309

2. เมื่อพิจารณาตามอาชีพ กลุ่ม `Entertainer` มีอัตราตอบรับข้อเสนอสูงที่สุดที่ 2.0492% หรือ 5 รายการจาก 244 รายการ

3. เดือนที่มีอัตราตอบรับข้อเสนอสูงที่สุดคือ `Aug` ที่ 1.9537% หรือ 217 รายการจาก 11,107 รายการ อย่างไรก็ตาม ข้อมูลต้นฉบับระบุเฉพาะชื่อเดือนโดยไม่มีปี จึงไม่สามารถใช้ผลนี้อธิบายแนวโน้มแบบหลายปีได้

4. คอลัมน์ `dcspend_last_30d` มีค่าติดลบ 17 แถว 

## Data quality and sensitivity

- หลังตัด Exact duplicate excess rows ออก เหลือข้อมูล 213,820 แถว และมีอัตราตอบรับข้อเสนอ 1.2263% (ผลลัพธ์นี้ใช้สำหรับเปรียบเทียบผลกระทบของข้อมูลซ้ำเท่านั้น ส่วนการวิเคราะห์หลักยังคงใช้ข้อมูลต้นฉบับทุกแถว)
- ไม่มีคอลัมน์ใดมีสัดส่วน missing เกิน 5%
- missing ในคอลัมน์ numeric จะไม่ถูกนำไปคำนวณ numeric summaries ส่วน missing ในคอลัมน์ categorical จะแสดงเป็น `Unknown`
