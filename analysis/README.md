# Data Analysis

ส่วนนี้เป็น Test Case #1 ด้านการสำรวจและอธิบายข้อมูลเท่านั้น

- `data/raw/` เก็บ CSV และ data dictionary ต้นฉบับ
- `data/derived/` เก็บ aggregate ที่สร้างซ้ำได้
- `notebooks/` เก็บ notebook
- `powerbi/` เก็บ PBIP dashboard, semantic model, Power Query และ DAX
- `reports/` เก็บ data profile และรายงานวิเคราะห์
- `shared/metric_contract.json` เป็นนิยาม metric กลาง
